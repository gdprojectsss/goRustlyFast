### Added

- `disown` (with `-h`, `-a`, `-r`, job specs and pids), `times`, `wait -n`, `wait -f` and `wait -p var`, `jobs -l`, `-p`, `-r`, `-s` and `-n`, `kill -l NUMBER` and `kill -l NAME`, `trap -p NAME`, and `DEBUG` and `RETURN` traps.
- `set -E` (errtrace) and `set -T` (functrace): without them the `ERR`, `DEBUG` and `RETURN` traps are not inherited by functions, subshells and command substitutions, as in bash.
- `shopt -s inherit_errexit`.
- `exec -a name`, `exec -c` and `exec -l`.
- `time -p` and `TIMEFORMAT`.
- A shell script without a `#!` line runs as a grfsh script, as in bash; a binary that cannot be executed reports "cannot execute binary file".

### Fixed

- `wait PID` treated the pid as a job number. It now waits for that process, returns the status of a background job that already finished (also when asked again), and reports "pid N is not a child of this shell" with status 127 for other pids. `wait` with no arguments returns 0, as in bash.
- `wait` can be interrupted: Ctrl-C stops it in an interactive shell, and a trapped signal runs its trap right away and makes `wait` return 128 plus the signal number.
- `trap '...; exit 8' INT` inside a `while` loop exited with status 0 instead of 8.
- An `EXIT` trap now runs when the shell is killed by a signal such as `TERM`, `HUP` or `INT`, including while it waits for a command, and `EXIT` traps set inside `( ... )` or `$( ... )` run when that subshell ends.
- A script that receives Ctrl-C while its foreground command ignores it waits for the command and carries on when the command exits normally, as in bash. Background commands in scripts ignore `SIGINT`, and the shell itself ignores `SIGQUIT`.
- Background jobs and process substitutions are reaped after every command, so long loops no longer pile up zombie processes until `fork` fails.
- Writing to a closed pipe no longer spins at 100% CPU: `grfsh -c 'while :; do echo x; done' | head -1` stops at once with status 141. Builtins report write errors, so `echo hi >&-` prints "write error: Bad file descriptor" and returns 1.
- `exec 3>file` did not pass descriptor 3 to external commands when the file opened as descriptor 3, and `{ ...; } 3>file` left descriptor 3 open afterwards.
- Here-strings and small here-documents use a pipe instead of a temporary file, which makes them much faster.
- "command not found", "No such file or directory" and "Is a directory" errors respect the command's redirections, so `nopecmd 2>/dev/null` is silent.
- `set -e` is no longer inherited by command substitutions, so `x=$(false; echo y)` sets `x` to `y`, as in bash.
- A function whose body is a subshell, `f() ( exit 3 )`, returned 0 instead of the subshell's status.
- `$LINENO` and error locations after a function call point at the caller again.
- `kill -l` prints the numbered signal table and knows every signal; `kill %1` works in scripts and stopped jobs are continued after the signal.
- `trap -p` and `trap` print `SIGINT` style names in signal number order, accept `--`, and `trap - NAME` restores the shell's own default handling.
- `jobs` uses bash's layout, shows finished jobs once with `Done` or `Exit N`, and lists the parent shell's jobs inside pipelines and command substitutions.
- `timeout 1e20 true` crashed the shell, and `timeout -s KILL` now returns 137 like GNU timeout.
- `fg` and `bg` say "no job control" in scripts.
