### Added

- `scripts/spec-tests.sh` runs the Oils shell spec tests (fetched at a pinned commit, about 2,750 cases in 130 suites) against grfsh and bash 5. CI fails when a case outside `scripts/spec-baseline.txt` fails.
- `scripts/differential.sh` compares grfsh with bash 5 on the 515 cases and scripts in `tests/differential`. It has an allow list for intentional differences and a list of known failures.
- A `run` fuzz target executes arbitrary bytes as a script inside a sandbox that refuses external commands, file writes outside a temporary directory and unbounded forking. CI runs it for two minutes.

### Notes for the integrator

- After merging the round of fixes, regenerate both baselines with a release build: `scripts/spec-tests.sh --write-baseline scripts/spec-baseline.txt` and `scripts/differential.sh --write-baseline`. The baselines were generated on macOS with Homebrew bash 5.3. The Ubuntu leg of the `differential` CI job is `continue-on-error` until a Linux baseline exists; its spec failures file is uploaded as an artifact.
- The fuzz `run-smoke` job runs on pushes and pull requests and will fail until the panics in the fuzz findings (`unset ""`, NUL bytes reaching the environment) are fixed.
- `src/sandbox.rs` has an allow list of builtins. Builtins added in this release (let, builtin, caller, disown, times, enable, compgen, ...) are refused in the sandbox until someone adds the safe ones to `ALLOWED_COMMANDS`.
- When the bytes layer (area 7) lands, `sandbox::run_untrusted` should decode its input with it instead of `String::from_utf8_lossy`.
- CONTRIBUTING.md documents the new scripts; README needs no change.
